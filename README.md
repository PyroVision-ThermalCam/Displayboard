## About

PyroVision is an open-source project designed to capture and process thermal images using ESP-IDF. It provides functionalities for WiFi management, HTTP server communication, WebSocket handling, and image encoding. This project is ideal for IoT applications requiring thermal imaging capabilities.

## Features

### Hardware

- Lepton 3.5 LWIR camera
- OV5640 RGB camera
- RTC
- Internal temperature sensor for compensation
- LiPo battery
- LiPo charger
- Battery measurement
- SD card
- RGB LED
- LED flash
- Display with Touchscreen
